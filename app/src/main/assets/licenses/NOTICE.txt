# Third-party software

ChipPlayer 199x original application code and artwork retain the MIT license.
The combined APK contains GPL-covered PSF emulation and is distributed under
**GPL version 3**; see [COPYING-GPL-3](COPYING-GPL-3). Complete corresponding
source, local modifications and build scripts are in this repository.
No game music or ROMs are distributed in this repository or APK.
No game artwork is bundled; the player uses its audio-driven pixel spectrum.

## Game Music Emu

Unmodified sources from https://github.com/libgme/game-music-emu at commit
`f68963b1de0633149b05732113d3c3113c6f63a1` are included in
`third_party/game-music-emu`. Game Music Emu is LGPL 2.1 or later.
The build uses the LGPL Nuked YM2612 implementation, not the GPL MAME option.
Individual source headers retain copyright notices. Full license text is included
in `third_party/game-music-emu/license.txt`; the upstream GPL text is retained too.

`libgme.so` is linked dynamically. Complete source and build instructions are
included here so recipients can rebuild or replace it and rebuild the APK.
Android permits installing a modified, re-signed APK after uninstalling the old
one (uninstalling removes its private library). No restrictions on reverse
engineering for debugging modifications to this library are imposed.

## unarr RAR reader

LGPLv3; revision `29084afa8d507b34558f2936ec789edcd116e306` from
https://github.com/selmf/unarr. Sources and COPYING are in `third_party/unarr`.
Built as a separate `libunarr.so`; used for RSN, including solid RAR4. It replaces
Junrar, and no UnRAR-licensed code is linked into this APK. Native binaries can be
rebuilt from the app CMake project using the included source.

## PSF emulation

Audio Overload and PeOPS files from Audacious plugins revision
`419f26c28cdf430f4af2d9f659befcc3474aeae5`. BSD and GPL 2-or-later notices are
retained in `third_party/psf-core`; this combined build chooses GPL version 3.
See that directory's SOURCE.md for local threading and integration changes.
No proprietary PlayStation BIOS is bundled or required. PSF2 is not supported.

## MIDI synthesis and Pixel GM

TinySoundFont by Bernhard Schelling (based on SFZero by Steve Folta), MIT.
Unmodified header and licence from revision
`853a0a171759f1ddba0de1442133a75912bbeffa` of
https://github.com/schellingb/TinySoundFont are in `third_party/tinysoundfont`.
The app adds a bounded SMF scheduler and SF2 table validation; FluidSynth is not
bundled. No SoundFonts from TinySoundFont's examples are distributed.

The included **Pixel GM** SoundFont and optional **Pixel Steps** MIDI demo are
original MIT-licensed synthetic waveforms and an original musical phrase,
respectively. No game audio was sampled. Rebuild them with
`scripts/generate-soundfont.py` and `scripts/generate-midi-demo.py`.
Pixel GM provides 128 GM program slots and a percussion preset with a deliberately
simple retro sound; it is not an acoustic instrument library or a recreation of a game.
User-imported banks retain their own licences and are not redistributed by the app.

## Original player skin

The nine-patches and PNG sprites in `app/src/main/res/drawable-*/` are
original PixelSPC pixel artwork under this repository’s MIT license. Regenerate
them with `python3 scripts/generate-skin.py`; no third-party skin images,
Winamp artwork, logos, or music are bundled.
